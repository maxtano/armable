# Archive

Earlier experiments, kept for reference. Nothing here is built, tested or deployed.

- **direction-lab** — three interaction samples and a four-tool MCP server against a simulated drone. It proved that an assistant on a subscription could drive Lucidity's tools. The real tool server now lives in [`drone-studio/server`](../drone-studio/server).
- **local-workspace** — the old local Lucidity app (Home, Tools, Music, Drone Show, Code) with its built-in agent harness, Vite dev-server APIs, GitHub Pages demo, dev fixtures, tests and documents. Retired when the hosted app replaced it. Code it shared with the new app (storyboard editor, 3D stage, sound tools, design system) stays in [`drone-studio`](../drone-studio). To run it, check out commit `f7d5dfa`.
